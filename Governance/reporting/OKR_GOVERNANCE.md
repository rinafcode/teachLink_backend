## 1. How goals are set

Objectives and Key Results (OKRs) are set as follows:

- **Objectives**: Defined by the project lead in consultation with maintainers.
- **Key Results**: Each objective has 3-5 measurable key results.
- **Alignment**: OKRs must align with the project roadmap and community feedback.
- **Documentation**: OKRs are documented in the repository and accessible to all contributors.

## 2. Review cadence

| Activity | Frequency |
| --- | --- |
| OKR setting | Quarterly (start of each quarter) |
| Progress check | Bi-weekly |
| End-of-quarter review | Within 5 business days of quarter end |

## 3. How progress is reported

- Progress is tracked in the `Governance/reporting/` directory.
- Each key result has a status: on track, at risk, or off track.
- A summary is included in the monthly maintainer report.
